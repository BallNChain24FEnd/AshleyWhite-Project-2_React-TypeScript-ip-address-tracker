# Project II — React Development Reflection

Building my IP Address Tracker with React and TypeScript helped me understand how different components work together to create an interactive application. I chose to build on my first HTML, CSS, and JavaScript project so I could compare my original approach with React's component-based structure.

One important lesson was learning how to organize reusable components and pass information through props. I also practiced using `useState` to manage changing information and `useEffect` to handle side effects. Creating the custom `useIPLocation` hook helped me understand how related functionality can be organized and reused.

One of my biggest challenges was positioning the Leaflet map and keeping the black location marker visible across different screen sizes. I also had to learn how to connect the IPify API securely without exposing my API key. Researching React Leaflet, environment variables, and Vercel serverless functions helped me solve these problems.

Testing was another important part of the process. I successfully searched for `8.8.8.8` and `1.1.1.1`, confirmed that the information cards updated, and watched the map move to the returned locations. I also verified that the deployed application worked on Vercel.

Overall, this project strengthened my understanding of React, TypeScript, API integration, debugging, and deployment. If I continued improving it, I would focus on refining the map positioning and making the mobile experience even better.
